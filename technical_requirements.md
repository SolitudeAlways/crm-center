# Техническое задание (ТЗ)
## CRM для управления учебным центром

### 1. Краткое описание
Веб-приложение для администрирования учебного центра. Позволяет управлять студентами, преподавателями, группами, курсами, расписанием и посещаемостью.

### 2. Основные сущности

#### 2.1 Пользователь (User)
- id
- email
- имя
- фамилия
- отчество (необязательно)
- роль (админ, преподаватель, студент)
- пароль (хранить только хеш!)
- дата регистрации
- последний вход
- статус (активен/заблокирован)
- аватар (опционально)

#### 2.2 Группа (Group)
- id
- название
- преподаватель (связь с User)
- список студентов (связь с User)
- дата создания
- статус (активна/завершена)
- максимальное количество студентов
- описание

#### 2.3 Курс (Course)
- id
- название
- описание
- длительность (в неделях)
- стоимость
- уровень сложности
- категория
- требования к студентам
- программа курса

#### 2.4 Расписание (Schedule)
- id
- группа (связь с Group)
- курс (связь с Course)
- дата и время занятия
- длительность занятия
- аудитория
- тип занятия (лекция/практика)
- статус (запланировано/отменено/завершено)

#### 2.5 Посещаемость (Attendance)
- id
- студент (связь с User)
- расписание (связь с Schedule)
- статус (был/не был)
- причина отсутствия (опционально)
- комментарий

#### 2.6 Домашнее задание (Homework)
- id
- название
- описание
- срок сдачи
- максимальный балл
- прикрепленные файлы
- группа (связь с Group)
- курс (связь с Course)

#### 2.7 Оценка (Grade)
- id
- студент (связь с User)
- домашнее задание (связь с Homework)
- балл
- комментарий преподавателя
- дата оценки

#### 2.8 Комментарий (Comment)
- id
- автор (связь с User)
- содержание
- дата создания
- тип (к домашнему заданию/к курсу/к группе)
- связанная сущность

### 3. Основной функционал

#### 3.1 Аутентификация и авторизация
- Регистрация и авторизация пользователей (JWT)
- Восстановление пароля
- Двухфакторная аутентификация (опционально)
- Защита от CSRF
- Ограничение попыток входа (5 попыток в течение 15 минут)
- Требования к паролю:
  - Минимум 8 символов
  - Обязательно: заглавные и строчные буквы, цифры
  - Специальные символы (опционально)

#### 3.2 Управление пользователями
- CRUD операции для всех сущностей
- Управление ролями и правами
- Профили пользователей
- Загрузка и управление аватарами

#### 3.3 Управление учебным процессом
- Создание и управление группами
- Назначение преподавателей
- Распределение студентов по группам
- Управление курсами и программами
- Создание и редактирование расписания
- Отметка посещаемости
- Управление домашними заданиями
- Выставление оценок

#### 3.4 Отчетность и аналитика
- Генерация отчетов по посещаемости
- Статистика успеваемости
- Экспорт данных в Excel/PDF
- Графики и диаграммы

#### 3.5 Уведомления
- Email-уведомления о предстоящих занятиях
- Уведомления о новых домашних заданиях
- Уведомления об оценках
- Системные уведомления

### 4. Технические требования

#### 4.1 Backend
- NestJS (версия 10.x)
- TypeORM
- MySQL (версия 8.x)
- JWT-авторизация
- Валидация DTO
- Swagger для документации API
- Логирование (Winston)
- Unit-тесты (Jest)
- E2E тесты
- Docker-контейнеризация

#### 4.2 Frontend
- Vue 3 + TypeScript
- Pinia (хранилище)
- Vite (сборка)
- SCSS для стилей
- Axios для запросов к API
- Адаптивная верстка
- Поддержка темной/светлой темы
- Доступность (WCAG 2.1)
- Компонентный подход
- Unit-тесты (Vitest)

#### 4.3 Безопасность
- HTTPS
- Защита от XSS
- Защита от SQL-инъекций
- Rate limiting
- Валидация всех входных данных
- Безопасное хранение паролей (bcrypt)
- Регулярное резервное копирование

#### 4.4 Интеграции
- Google Calendar API
- Email-сервис (SendGrid/Mailgun)
- Система хранения файлов (AWS S3/Google Cloud Storage)

### 5. UI/UX требования
- Современный минималистичный дизайн
- Адаптивная верстка (мобильные устройства, планшеты, десктоп)
- Интуитивно понятный интерфейс
- Быстрая загрузка страниц
- Поддержка клавиатурной навигации
- Локализация (русский/английский языки)
- Анимации и переходы
- Обратная связь при действиях пользователя

### 6. Требования к производительности
- Время загрузки страницы < 2 секунд
- Время ответа API < 500мс
- Поддержка до 1000 одновременных пользователей
- Оптимизация изображений и статических файлов
- Кэширование данных
- Оптимизация запросов к базе данных

### 7. Документация
- API документация (Swagger)
- Руководство пользователя
- Техническая документация
- Документация по развертыванию
- Документация по тестированию

### 8. Требования к развертыванию
- Docker-контейнеры
- CI/CD пайплайн
- Мониторинг (Prometheus + Grafana)
- Автоматическое резервное копирование
- Стратегия обновления
- План масштабирования
